# studentmanagementTracker
The Student Grade Tracker is a beginner-friendly Java application developed to manage student marks and calculate grades. It allows the user to enter the number of students, their names, and their marks. Based on the marks entered, the system automatically assigns grades according to predefined grading criteria.

The application generates a student report displaying each student’s name, marks, and grade. It also calculates the average marks and identifies the highest and lowest marks among all students.

The project includes input validation to ensure that student names are not empty and marks are within the valid range of 0 to 100. It uses Object-Oriented Programming concepts and an ArrayList to store and manage student records.
